# Amazon KDP Print — instrukcja podpięcia książki

> Źródło: `Dropbox/Trustee_Book in a day/01_Admin/Jak podpiąc książkę w amazon print.docx`

## 1. Rejestracja w Amazon KDP

- Platforma **Amazon KDP** — darmowa, logowanie standardowym kontem Amazon
- Wymagane: dane do przelewów bankowych + ankieta podatkowa

## 2. Przygotowanie plików do druku

Dwa oddzielne pliki **PDF**:

### Wnętrze książki (Manuscript)

- Format książki: np. 5×8 lub 6×9 cali
- Odpowiednie marginesy (spady jeśli grafiki ucięte przy krawędziach)
- Eksport do PDF

### Okładka (Cover)

- Jeden płaski PDF: tylna okładka + grzbiet + przednia okładka
- Szerokość grzbietu zależy od liczby stron + gramatura papieru
- **KDP udostępnia kalkulator** — generuje szablon z dokładnymi wymiarami

## 3. Konfiguracja książki i ISBN

- Typ: Paperback (miękka) lub Hardcover (twarda)
- Uzupełnić: tytuł, opis, słowa kluczowe (SEO w sklepie Amazon)
- **ISBN:** KDP oferuje darmowy numer ISBN (zastrzeżenie: z tym numerem nie wydrukujesz w innej drukarni)

## 4. Ustalenie ceny i publikacja

- Amazon pokazuje **dokładny koszt druku** per egzemplarz (zależy od: objętość, kolor wnętrza, rynek — .pl / .de / .com)
- Ustalasz cenę detaliczną → system wylicza zarobek netto
- **Publikacja: do 72h** (weryfikacja techniczna plików)

## 5. Integracja ze stroną (trapdoor flow)

1. Po publikacji — skopiować link do książki w sklepie Amazon
2. Na bajkot.pl — przycisk **"Kup drukowaną wersję"** (+29 PLN)
3. Link kieruje na Amazon

### Pro Tip: podwójny zarobek

Zarejestrować się w **Amazon Associates** (program afiliacyjny):

- Link na stronie = link partnerski
- Zarobek: **tantiemy KDP** + **prowizja afiliacyjna** za sprowadzenie klienta

## Implikacje dla trapdoor flow

Trapdoor w bajkot.pl powinien:

1. Po wygenerowaniu PDF → upsell "Chcesz drukowaną wersję? +29 PLN"
2. Zbierać zamówienie (adres, płatność)
3. Wysłać maila z potwierdzeniem + linkiem do Amazon (affiliate link)
4. Alternatywnie: Amazon Print-on-Demand — klient zamawia bezpośrednio, my dostajemy tantiemy

### Otwarte pytania

- Czy robimy direct Amazon link (klient kupuje sam) czy my zamawiamy i wysyłamy?
- Jak generować okładkę dynamicznie (per dziecko/historia)?
- Czy darmowy ISBN KDP wystarczy, skoro każda książka jest unikalna?
- Format: 5×8 vs 6×9 cali — jaki najlepszy dla bajek z ilustracjami?
