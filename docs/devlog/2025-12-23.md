## LLM Logs viewer

Główna robota dnia. Nowa tabela `llmLogs` w schema - sessionId, action, model, systemPrompt, userPrompt, response, error, durationMs, timestamp. Index po sesji.

`convex/llmLogs.ts` - internal mutation `storeLlmLog`, query `getLlmLogs` (limit 20, newest first).

Zmodyfikowałem `llmClient.ts` - nowy interface `LlmLogContext` z ctx i sessionId. `chatJsonWithRetries` teraz loguje każde zapytanie. Trzeba było zmienić `rateLimitMutation` żeby zwracał sessionId.

Wszystkie 4 akcje w `ai.ts` (generateNextQuestion, scorePrompt, generateAssessmentReport, generatePlaybook) teraz przekazują logContext.

Frontend: nowy `DebugTabLlmLogs.tsx`. Lista logów z timestampami, kliknięcie otwiera modal. Modal ma dwie zakładki: Prompt (system fioletowy + user niebieski, color-coded) i Response (zielony lub czerwony dla błędu). Copy buttons wszędzie.
