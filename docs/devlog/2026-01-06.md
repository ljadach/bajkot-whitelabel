# 2026-01-06

## Co zrobiliśmy

Role-based access control (RBAC) z Clerk JWT custom claims. Debug panel i API teraz dostępne tylko dla adminów.

### Implementacja

**Nowe pliki:**
- `convex/lib/roles.ts` - helpery do weryfikacji ról:
  - `hasRole(ctx, role)` - sprawdza czy user ma rolę
  - `isAdmin(ctx)` - sprawdza czy admin
  - `assertRole(ctx, role)` - throw jeśli brak roli
  - `assertAdmin(ctx)` - throw jeśli nie admin

**Zmodyfikowane:**
- `convex/auth.ts` - dodane `api.auth.isAdmin` query dla frontendu
- `convex/llmLogs.ts` - wszystkie query zabezpieczone `assertAdmin()`
- `convex/ai.ts` - `debugListPrompts` zabezpieczone `assertAdmin()`
- `convex/config.ts` - `list` i `set` zabezpieczone `assertAdmin()`
- `src/components/debug/DebugRoot.tsx` - renderuje się tylko dla adminów

### Konfiguracja w Clerku

1. JWT Templates → edytuj template "convex"
2. Dodaj custom claim: `"isAdmin": "{{user.public_metadata.isAdmin}}"`
3. Dla adminów ustaw `publicMetadata.isAdmin = true` w Users

### Decyzje architektoniczne

1. **`config.get` publiczne dla zalogowanych** - używane przez frontend i backend do pobierania LLM_MODEL_GLOBAL. Nie ma tam sekretów, więc OK.

2. **`auth.isAdmin` dostępne dla zalogowanych** - każdy zalogowany user wie czy jest adminem. Minimalne ryzyko information disclosure, potrzebne dla frontendu.

3. **Admin może widzieć logi innych userów** - feature dla debugowania. `getLlmLogs` przyjmuje opcjonalny `clerkUserId` parametr.

4. **CORS wildcard w streaming.ts** - oznaczone `@security` TODO do zabezpieczenia przed produkcją.

5. **Exercises bez auth** - poprawione, teraz wymagają zalogowania.
