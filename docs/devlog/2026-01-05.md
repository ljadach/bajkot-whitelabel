### 3. Quick Tip Widget z Google Search Grounding
Główna funkcja dnia - widget "Do you know?" na stronie `/plan`:

**Backend:**
- Schema `quickTip` z polami `hook` (opcjonalny) i `content`
- Nowa akcja `quickTipAi.ts` używająca `@ai-sdk/google` z Gemini 2.0 Flash
- Google Search tool do groundingu w najnowszych źródłach
- Helper `quickTipAiHelpers.ts` (internal mutation)
- Mutacja `clearQuickTip` do regeneracji

**Prompty:**
- `quick-tip-system` - generuje JSON z `hook` (1-liner) + `content`
- `quick-tip-user` - kontekst profilu, chat summary, scores
- Hook ma max 80 znaków, intrygujący bez clickbaitu
- Content: konkretny, actionable, max 12 zdań

**Frontend:**
- Teaser card z hookiem, klik otwiera modal
- Modal z pełną treścią i lepszą typografią (leading-7)
- Regeneracja przy Regenerate w SummaryStep

### 4. SDK Version Hell
Największy pain point sesji - konflikty wersji:
- `@ai-sdk/google@3.x` wymaga Language Model v3 spec
- `@openrouter/ai-sdk-provider` wymaga `ai@^5.0.0`
- Rozwiązanie: `ai@5.0.117` + `@ai-sdk/google@2.0.52`
- Różnice API: `experimental_providerMetadata` → `providerMetadata`, `maxTokens` → `maxOutputTokens`

### 5. Widget Redesign
Pierwsza wersja za "premium" (ciemna, animacje). User feedback:
- Wyrzucić animacje
- Dopasować do jasnego stylu serwisu
- Poprawić typografię w modalu
- Powiększyć modal

Finalna wersja: biała karta, pomarańczowe akcenty, max-w-2xl modal, leading-7.

## Obserwacje

**SDK hell** - typowy problem Node.js. Wersje lecą jak szalone, peer deps się gryzą. W tym przypadku @ai-sdk/google v3 wydany niedawno, ale openrouter jeszcze nie nadążył. Rozwiązanie: pin do starszych wersji. Claude dobrze to debugował, sprawdzając `npm view` i szukając kompatybilnych wersji.

**Design feedback loop** - pierwsza wersja widgetu była "za bardzo premium" (ciemna, animacje, sparkles). User jednym zdaniem: "nie podoba mi się, wzoruj się na reszcie serwisu". Dobra lekcja - fancy != dobre. Spójność > wow effect.

**Teaser + Modal pattern** - dobry UX dla opcjonalnej treści. Hook buduje ciekawość, pełna treść nie zaśmieca głównego flow. Prompt engineering kluczowy - hook musi być intrygujący ale nie clickbaitowy.

**Google Search grounding** - działa, ale metadata ze źródłami jest w `providerMetadata.google.groundingMetadata.groundingChunks`. Dokumentacja Vercel AI SDK mogłaby być lepsza.
