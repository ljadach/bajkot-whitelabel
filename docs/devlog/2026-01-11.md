## Backend Logs w Debug Panelu

Dodano możliwość przeglądania logów backendu w panelu debug (dla adminów).

**Problem:** `console.log` z Convex actions trafia tylko do Convex Dashboard - nie było sposobu żeby zobaczyć je w aplikacji.

**Rozwiązanie:**
- Nowa tabela `backendLogs` (100 wpisów, auto-cleanup)
- `createLogger(ctx, source)` - wrapper który loguje do DB + console
- Nowa zakładka "Backend Logs" w debug drawer z filtrami po poziomie

Migracja: zamiana `console.log('[source] msg')` na `log.info('msg')`. Zrobione dla `streaming.ts` jako przykład.

## Śledzenie Czasu w Kursie

**Problem:** `totalTimeMinutes` w dashboard zawsze pokazywał 0 - mutacje `startChapter`, `completeChapter`, `recordTimeSpent` istniały w backendzie ale nikt ich nie wywoływał.

**Rozwiązanie:**
- Nowa query `getChapterStatus` - status pojedynczego rozdziału
- Hook `useChapterProgress`:
  - `startChapter` przy otwarciu rozdziału
  - `recordTimeSpent(+60s)` co minutę (setInterval)
  - `completeChapter` na żądanie użytkownika
- UI w ReaderView:
  - Badge statusu (In Progress / Completed)
  - Wyświetlanie czasu (`Xm spent`)
  - Przycisk "Mark Chapter as Complete" z ikoną ✓

Czas nalicza się w pełnych minutach gdy użytkownik jest obecny na stronie.

## Auto-Fill Chat - debug tool

Nowa funkcjonalność w panelu Debug do automatycznego wypełniania formularza intake.

**Nowe pliki:**
- `convex/autoFillChat.ts` - Convex action generujący odpowiedzi
- `src/components/debug/AutoFillContext.tsx` - React context

**Persony:** CTO, CFO, Hydraulik, Marketing Manager, Custom

**Jak działa:**
1. Rozwiń "Auto-Fill Chat" w Debug → Session
2. Wybierz personę
3. Kliknij "Activate"
4. Na `/chat` odpowiedzi generują się automatycznie po 0.2s

LLM (Claude 3.5 Haiku via OpenRouter) dostaje opis persony, historię rozmowy i aktualne pytanie. Obsługuje wszystkie typy widgetów.
