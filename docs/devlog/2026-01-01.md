# 2026-01-01

## Enterprise Redesign

Kompletny redesign graficzny aplikacji AITutor pod odbiorców enterprise (partnerzy McKinsey, szefowie HR). Estetyka wzorowana na Anthropic Console, OpenAI Dashboard - czysta, minimalistyczna, profesjonalna.

### Problem

Poprzedni design miał "startup vibes" - gradienty, kolorowe akcenty, casualowy styl. Nie pasował do grupy docelowej (C-level executives, enterprise buyers).

### Rozwiązanie

Nowy design system z neutralną paletą kolorów i komponentami enterprise-grade.

**Design tokens** (`src/index.css`):
```css
:root {
  --bg: #ffffff;
  --bg-subtle: #fafafa;
  --ink: #0f0f0f;
  --ink-secondary: #525252;
  --muted: #737373;
  --line: #e5e5e5;
  --accent: #0a84ff;
}
```

**Komponenty CSS** (`@layer components`):
- `.btn-primary` - ciemny przycisk główny (bg-neutral-900)
- `.btn-secondary` - biały z obramowaniem
- `.btn-ghost` - przezroczysty hover
- `.btn-icon` - okrągły przycisk ikonowy
- `.card` - karta z subtelnym border
- `.card-elevated` - karta z cieniem
- `.badge` - etykieta (neutral-100)
- `.input` / `.textarea` - pola formularza
- `.spinner` - animacja loading
- `.prose-enterprise` - style dla markdown content

### Zmiany w komponentach

**Header** (`App.tsx`):
- Wysokość 56px, sticky
- Minimalistyczne logo (stacked layers SVG)
- Separator pionowy przed UserButton
- Przyciski icon-only (StartOver, Share)

**WelcomeStep**:
- Duży heading z `tracking-tight`
- Consent card z checkboxem
- CTA "Let's begin" zamiast kolorowego przycisku

**Chat** (`ChatStep`, `ChatMessage`, `ChatWidget`):
- Alternatywne tła (white/neutral-50)
- Avatary 7x7 z rounded-lg
- AI avatar: neutral-200, User avatar: neutral-900
- Input z pill-shaped suggestions
- Hint "Ctrl+Enter" przy przycisku

**SummaryStep**:
- Dwie karty (Profile Summary, Assessment)
- Badge'y dla tools/needs
- Prose styling dla markdown assessment

**PlanStep**:
- Karty z uppercase label "Page X"
- Hover state z border-neutral-300
- Przycisk "Continue to Course Preview"

**CoursePreviewStep** + komponenty:
- `StatusBadge` z kolorowymi kropkami (pending/generating/completed/failed)
- `ChapterNav` z numerowaną nawigacją
- `HandbookContent` z prose-enterprise
- Progress bar dla generacji

**TutorFlow**:
- Chat step: full-height flex container
- Inne kroki: min-h-full z padding

### Statystyki

17 plików zmodyfikowanych, +1300/-565 linii.

Główne zmiany:
