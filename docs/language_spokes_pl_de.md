# **Language Spokes (Polish & German)**

This document provides the language-specific implementation rules (Spokes) for Bajkot. These guidelines are derivatives of the **Global Hub** (refer to editorial_style_guide.md). All writers must adhere to the Hub’s core philosophy of efficiency and scannability while applying the linguistic nuances defined below.

## **1\. Polish Spoke (PL)**

The Polish implementation prioritizes modern professional directness while managing the complexities of Slavic grammar.

| Feature            | Rule                                                               | Example                                        |
| :----------------- | :----------------------------------------------------------------- | :--------------------------------------------- |
| **Formality**      | Use **"Ty"** (Direct/Informal). Avoids legacy corporate stiffness. | "Oblicz wynik" instead of "Proszę obliczyć..." |
| **Declension**     | **Bajkot** is indeclinable (_nieodmienne_). Do not add suffixes.   | "Korzystaj z Bajkot" (NOT Bajkota).            |
| **Capitalization** | Follow Hub "Down-style" for UI, but respect proper nouns.          | "Ustawienia konta" (Sentence case).            |
| **Active Voice**   | Explicitly avoid the passive "zostało zrobione."                   | "System zaktualizował dane" (Active).          |
| **Possessives**    | Minimize "Twoje/Twój." If ownership is implied, delete the word.   | "Profil" instead of "Twój profil."             |

## **2\. German Spoke (DE)**

The German implementation balances the Hub's efficiency with the non-negotiable structural requirements of German grammar.

| Feature            | Rule                                                                     | Example                                                   |
| :----------------- | :----------------------------------------------------------------------- | :-------------------------------------------------------- |
| **Formality**      | Use **"Du"** (Professional/Modern). Standard for high-tech MBA contexts. | "Erstelle dein Profil" instead of "Erstellen Sie..."      |
| **Declension**     | **Bajkot** is indeclinable. Avoid the genitive "-s".                     | "Die Power **von Bajkot**" (NOT Bajkots).                 |
| **Capitalization** | **Nouns must remain capitalized.** This is a Hub exception.              | "Deine Einstellungen" (Settings).                         |
| **Compound Nouns** | Use hyphens for scannability. Avoid "word-monsters."                     | "KI-Training" instead of "Künstlicheintelligenztraining." |
| **Directness**     | Use the Imperative for UI actions to drive speed.                        | "Jetzt starten" (Start now).                              |

### **Linguistic Guardrails**

- **Sentence Length:** German text expands significantly. You must strictly enforce the Hub's **1–2 sentence paragraph** rule to prevent layout breaks.
- **Clarity:** Prioritize "Direct German" over bureaucratic phrasing. If a shorter synonym exists, use it.
